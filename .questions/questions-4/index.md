Q: What is the difference between defining and calling a function?

A: The difference between defining and calling a function in JavaScript (and most programming languages) is based on the action you're performing.

Defining a function: 

Defining a function is the process of creating the function and specifying its behavior (the code it should execute). When you define a function, you're essentially setting up a reusable block of code that can be run later.

Calling a function:

Calling a function means executing the function you defined earlier. It’s like telling the program to run the block of code that’s inside the function.
